# Specyfikacja todo.py

## Użycie:
- `python todo.py dodaj "Kup mleko"` -> dodaje zadanie, wypisuje jego numer
- `python todo.py lista` -> wypisuje: numer, [ ]/[x], treść
- `python todo.py zrobione 1` -> oznacza zadanie jako wykonane
- `python todo.py usun 1` -> usuwa zadanie

## Wymagania:
- Dane trzymane w pliku `zadania.json`.
- Nieistniejący numer = czytelny komunikat błędu.
