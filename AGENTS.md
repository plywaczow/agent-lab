# Zasady pracy w tym repozytorium
- Odpowiadaj po polsku, maksymalnie 10 zdań.
- Kod i nazwy zmiennych po angielsku, komentarze po polsku.
- Najpierw pokaż plan, potem zmieniaj pliki.
- Nie instaluj niczego bez pytania.
- Nie dotykaj plików .env ani folderu .git.
- Uruchamiaj testy: python -m unittest.
- Gdy nie jesteś pewien, powiedz to wprost.
